# Ресурсы ВБетон

`vbeton-logo.pdfpath` содержит исходные векторные контуры основного логотипа со страницы 4 предоставленного гайдбука. Изменены только перенос начала координат и запись RGB-оператора. Цвета, кривые, пропорции и взаимное положение частей сохранены. Генератор включает контуры в PDF как векторную форму, без растеризации.

Происхождение ресурсов и SHA-256 записаны в `manifest.json`. Статические начертания Roboto Flex в соседнем `fonts/` получены из исходного вариативного файла Google Fonts инструментом FontTools 4.67.0. В PDF используются Weight 280 и 700, Width 91; остальные оси закреплены на исходных значениях. Лицензия шрифта находится в `fonts/OFL-RobotoFlex.txt`.

Логотип и гайдбук предоставлены пользователем. Общая MIT-лицензия кода проекта на них не распространяется.
