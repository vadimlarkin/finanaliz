# Утверждённый макет «Кредитный комитет 2.0»

Применяй `credit-committee-2.0` как обязательный образец оформления. Пользователь утвердил одностраничную кредитную оценку 20.10.2026. Дальнейшие изменения вноси точечно по его поручению, сохраняя остальной макет. Прежняя композиция версии 1.0 заменена этим образцом.

## Идентификация образца

Утверждённый пользователем PDF хранится отдельно. Он содержит сведения реального заёмщика: не включай его, идентификаторы или данные заёмщика в общий репозиторий и распространяемый пакет. В пакет включены только геометрия, генератор и вымышленные проверки. Содержание образца не является данными для других проверок.

## Данные представления

После анализа создай отдельный `report.json`. Сохраняй только следующие поля; лишние ключи отклоняются:

- `layout_version`: строго `credit-committee-2.0`.
- Строки `company`, `metadata`, `summary`, `loan_note`.
- `headlines`: ровно 3 объекта `value`, `label` — число и его смысл с единицей, периодом и источником.
- `earnings_period_label`: единица и период левой таблицы.
- `earnings_rows`: ровно 4 объекта `label`, `value` — выручка без НДС, результат до процентов и налога, маржа, процентный расход. Сохраняй этот порядок; отсутствие показывай явно.
- `scenario_title`: заголовок правой колонки с явным указанием сценарного характера.
- `scenario_rows`: ровно 3 объекта `margin`, `earnings`, `coverage`. Сценарии согласуй с методикой и условиями проверки. Значения 5/10/15% и 40/45% из образца не становятся допущениями по умолчанию.
- `current_note`, `scenario_note`, `stress_note`: ограничения текущих данных, допущения сценариев, стресс. При отсутствии оснований явно указывай недоступность расчёта.
- `debt_title`, `debt_main`, `debt_note`: долг на дату, основной долг, отдельно проценты, полнота и сроки.
- `bank_title`, `bank_note`: состав выписок и существенные наблюдения с источниками. Допускаются явные переводы строк, но блок остаётся на месте.
- `questions`: ровно 3 непустые строки; генератор добавляет номера 1–3.
- `sources`, `limitations`: источники и ограничения внизу.

Все значения — строки, кроме указанных массивов и объектов. Не передавай стили или координаты. Суммы представляй с десятичной запятой и указанной единицей. Для отсутствующих чисел используй «Нет данных» и сохраняй место поля. Обязательные поля не опускай. Генератор отвечает за представление; достоверность чисел проверяй по оригиналам и рабочему аудиту до запуска.

```bash
python <skill-dir>/scripts/render_report.py <work-dir>/report.json <work-dir>/borrower-dashboard.pdf
python <skill-dir>/scripts/check_terminology.py <work-dir>/borrower-dashboard.pdf <work-dir>/report.json <work-dir>/analysis.json
```

Называй сумму без процентов и комиссий **основным долгом** в соответствующем падеже. Проверка терминологии обязательна и блокирует выпуск при нарушении.

## Проверка результата и правки

При переполнении сокращай текст без потери существенных фактов. Генератор прекращает работу атомарно, сохраняя предыдущий PDF. Если важные факты не помещаются, сообщи о конфликте содержания и одного листа, согласуй приоритеты. Не меняй оформление для обхода ошибки.

Проверь одну страницу, читаемость, неизменность размещения, шрифтов, размеров и цветов. Для одинакового JSON, шрифтов и окружения PDF должен совпадать побайтово. Детальные расчёты и пять аналитических показателей сохраняй в рабочих файлах; одностраничный отчёт не заменяет проверку полноты анализа.

По запросу на мелкую правку меняй только названный элемент. Изменение геометрии или стилей сопровождай новой версией и обновлением проверок; не переоформляй остальные блоки по своему усмотрению.
