# Фиксированный макет «Кредитный комитет»

Версия: `credit-committee-1.0`. Выбран пользователем 19.10.2026 по варианту №2. Это обязательный формат отчёта, а не стилистический пример для свободной интерпретации.

## Генерация

Используй только `scripts/render_dashboard.py`. Каноническая геометрия, палитра и типографика находятся в этом скрипте: `SLOTS`, константы цветов и фиксированные координаты таблицы. Данные берутся из входного JSON; расчёты повторно выполняет `analyze.py`. Название скрипта сохранено для совместимости прежних команд.

Лист — A4, 595,28 × 841,89 pt, вертикальный. Поля — 36 pt. Шрифты — включённые Liberation Sans Regular и Bold с проверкой контрольных сумм. Это распространяемая метрически совместимая замена Arial из согласованного макета. Знак рубля берётся из включённого DejaVu Sans, также проверяемого по контрольной сумме. Системная установка шрифтов на оформление не влияет. ReportLab закреплён в `scripts/requirements.txt`.

## Неподвижная композиция

Сохраняй следующий порядок и закреплённые места:

1. Верхняя строка: название отчёта и тип оценки.
2. Заёмщик и заголовок «Заключение по новому займу».
3. Серая плашка с синей вертикальной линией: вывод и доступность расчётов.
4. Три колонки: сумма, ставка, срок и порядок возврата.
5. Таблица: «Показатель / Значение / Прочтение», пять строк в установленном порядке. Строка после нового займа выделяется светло-синим фоном.
6. Стресс-сценарий: подпись слева, значение справа, ограничение под ними.
7. Условия дальнейшего рассмотрения: существенные наблюдения и точечные вопросы.
8. Нижняя часть: источники, даты, ограничения и версия макета.

В таблице показывай число и короткую интерпретацию. Цвет фона, линия выделения и сетка остаются одинаковыми при любом уровне риска; риск раскрывается текстом. Спидометры в этом макете отсутствуют.

## Пределы изменяемого содержания

Заполняй компанию, даты, условия сделки, выводы, пояснения, вопросы и источники. Числовые значения и статусы получай из расчётов. Для отсутствующего значения выводи «Нет данных», для неприменимости сохраняй пояснение. Пустой показатель сохраняет свою строку и положение остальных элементов.

Размеры и позиции полей, гарнитура, отступы, цвета, разрядность чисел, порядок блоков и строк не являются параметрами запроса. В коде отдельно закреплены размеры надписи «Нет данных»; это фиксированное состояние поля, не подбор размера под содержание.

При переполнении сократи текст без потери существенных фактов и повтори запуск. Если это невозможно, сообщи о конфликте содержания и вместимости шаблона. Генератор отклоняет переполнение атомарно: не обрезает текст, не уменьшает шрифт, не переносит блоки и не добавляет страницу. Предыдущий файл остаётся целым.

Изменяй дизайн только по отдельному запросу пользователя: обнови генератор, номер версии, эталон и проверки вместе. Для побайтового сравнения используй одну версию Python, ReportLab и одни файлы шрифтов. Фиксация макета не делает извлечение фактов и аналитические формулировки модели детерминированными; воспроизводимость PDF проверяется по одному и тому же входному JSON.
