# Domain docs

Проект использует единый контекст: `GLOSSARY.md` в корне и архитектурные решения в `docs/adr/`.

Перед исследованием предметной области прочитай существующий словарь и решения по затрагиваемой теме. Если этих файлов ещё нет, продолжай работу: создавай их, когда появляется конкретный согласованный термин или решение.

Словарь содержит определения и связи предметных понятий. Используй формат `vendor/mattpocock/skills/domain-modeling/GLOSSARY-FORMAT.md`. Требования, задачи и детали реализации размещай в соответствующих документах проекта.

Создавай ADR, когда решение дорого изменить, его причина неочевидна будущему читателю и был реальный выбор между альтернативами. Используй `vendor/mattpocock/skills/domain-modeling/ADR-FORMAT.md`.

При противоречии нового изменения существующему ADR укажи это явно и объясни основание для пересмотра.
