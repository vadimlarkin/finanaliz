# Финансы заёмщика 0.1.0

Дата выпуска: 05.11.2026. Первый нумерованный выпуск навыка `borrower-financial-analysis`. Номер навыка отделён от версий движка и макетов.

## Состав

- Корпоративная проверка обязательного минимума и одностраничный отчёт ВБетон, макет `investor-one-page-2.2`.
- Отдельный порядок ИП без бухучёта, фиксированная форма `ip-investor-one-page-3.2`, расчёт кредитной нагрузки на срок конкретного нового займа.
- Проверка подготовленных банковских операций, категорий, встречных переводов и независимых банковских итогов.
- Получение исходников с общего диска «ВБетон» по папке, полному пути или ссылке. Включены проверка размера и хешей, сохранение структуры и версий, реестр происхождения, продолжение после обрыва и явные ошибки доступа.
- Самодостаточный payload со шрифтами, логотипом, схемами, вымышленными образцами и манифестом SHA-256. Инструменты разработки и рабочие документы в установочный архив не входят.

## Проверки и ограничения

131 детерминированный тест, включая 17 тестов получения с Диска. Проверены YAML, локальные ссылки, терминология и контрольные суммы payload. На AirM5 фактически скачан безопасный служебный README, 1023 байта, с совпадением MD5; проверено повторное использование полученного файла. Сценарии вложенности, пагинации, обрывов и ошибок проверены отдельно с имитацией внешнего API.

Расчёты требуют Python 3.9+, ReportLab и pypdf. Для Диска требуется отдельная авторизация; на AirM5 используется macOS Keychain. Установка навыка не переносит доступы на другие устройства.

Решение о финансировании остаётся кредитору. Полный пакет реального заёмщика по новому способу получения при выпуске не проверялся. Детерминированные тесты не доказывают качество финансового вывода модели.
