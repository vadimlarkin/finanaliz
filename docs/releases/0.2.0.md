# Финансы заёмщика 0.2.0

Дата выпуска: 05.11.2026.

Добавлены восемь локальных инструментов: расчёт денежных потоков, сверка пересекающихся выписок, подтверждение собственных переводов, импорт CSV по явному профилю, постраничное извлечение PDF с локальным OCR и кешем, свод долгового реестра, график нового займа и единый запуск выбранных расчётов с выпуском PDF.

Корпоративная ветка проверяет обязательный минимум до чтения финансовых данных. Для ИП допускается ограниченный разбор с явными пробелами. Источники и ручные решения сохраняются с контрольными суммами. Неизвестные сведения не подменяются нулями. PDF требует отдельной визуальной проверки.

Пройдены 252 детерминированных теста на принятой реализации; корпоративный и ИП образцы проверены визуально. Макеты сохранены: компания 2.2, ИП 3.2. Номер выпуска навыка отделён от версий расчётных схем и макетов.

Требуются Python 3.9+, ReportLab и pypdf. OCR использует доступный локальный движок, на AirM5 проверен Apple Vision. Для Tesseract нужны языки rus+eng. Авторизация общего диска настраивается отдельно на каждом Mac. Проверки скриптов не подтверждают качество финансового вывода модели и полноту документов реального заёмщика.
