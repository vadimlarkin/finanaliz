# Проверка версии 1.0.0

Проверено 19.10.2026 на вымышленных данных. Реальные заёмщики в тестах не используются.

## Автоматические проверки

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```

Набор проверяет независимые числовые примеры, смешанные периоды, неполноту и противоречия, вычет разовых доходов посредника, корректировку потока на портфель, отрицательный капитал, нулевые знаменатели, повторный учёт процентов, даты, источники, неизвестную ставку, точный график, стресс, одностраничность PDF, отображение кириллицы и отказ при переполнении.

PDF-тесты требуют reportlab и pypdf; при их отсутствии помечаются как пропущенные. Выпуск проверялся с обеими установленными зависимостями, без пропусков. Одинаковый вход дал одинаковые PDF-байты в одной среде; это не гарантия одинаковой аналитической оценки разными моделями.

## Проверка поведения навыка

Отдельная сессия получила только инструкции навыка и исходные вымышленные документы финансового посредника. Она самостоятельно подготовила входной JSON, расчёты, один лист PDF и изображение для осмотра. Ожидаемые ответы и готовый входной JSON ей не передавались.

Полученные значения: покрытие процентов 1,50×, долг/капитал 1,00× с нейтральной шкалой, деньги на 90 дней 2,50×, денежное покрытие 1,11×, после займа 1,15×, стресс −20%: 0,92×. Указаны ограничения портфеля, календаря и источника возврата тела. Арифметика совпала с независимыми контрольными примерами.

Это один сценарий проверки поведения модели, а не измеренная точность извлечения любых PDF, сканов или банковских выгрузок. Распознавание документов и обоснованность введённых фактов требуют проверки агентом по оригиналам.


## Фиксированный макет credit-committee-1.0

Выбран 19.10.2026. Проверены 30 автоматических сценариев без пропусков: прежние расчёты, состав таблицы, одинаковые PDF-байты при одинаковом JSON в одной среде, прямоугольники и координаты заголовков утверждённого макета во всех четырёх примерах, отсутствие выдуманных условий займа и атомарный отказ при переполнении. Все четыре PDF визуально осмотрены после рендеринга. Шрифты и версия ReportLab закреплены.

Проверки инструкций отделены от тестов скрипта. По чтению маршрутов навыка: подходящий запрос «проверь компанию по отчётности» приводит к фиксированному генератору; похожий запрос об управлении личным бюджетом вне области навыка; неполные и противоречивые данные должны сохранять строки таблицы с отсутствующим значением и пояснением. Для этих трёх запросов новый независимый прогон модели не выполнялся. Статические проверки не доказывают одинаковое извлечение фактов и формулировки разных моделей.

## Обязательный субагент-аналитик — 19.10.2026

Изменены инструкции оркестрации и стартовый запрос; логика скриптов и макет прежние. Вход — запрос проверки заёмщика с доступными документами; ожидаемый результат — анализ выполнен отдельным субагентом, основной агент возвращает проверенный результат. Критерий успеха — наблюдаемый запуск одного аналитика с доступом к исходникам и завершённый отчёт, а не только сообщение о делегировании.

Проверка по чтению инструкций, без независимого прогона модели:

- Подходящий запрос: «Проверь ООО по отчётности и ОСВ» — основной агент запускает одного аналитика и передаёт исходники; аналитик выполняет шаги 1–5 без повторного делегирования.
- Похожий запрос вне области: «Разбери мой семейный бюджет» — финансовый навык не применяется; правило запуска аналитика не активируется.
- Неполные или противоречивые данные: аналитик отмечает отсутствующие показатели, продолжает доступные расчёты и передаёт точечный вопрос основному агенту.
- Уточнение существующей проверки: дополнительные документы идут прежнему аналитику; новая независимая проверка другого заёмщика получает отдельного.
- Субагенты недоступны: ограничение сообщается явно; анализ основным агентом требует прямого указания пользователя.

Детерминированные тесты расчётов не подтверждают эти маршруты поведения модели. Независимый прогон обновлённой оркестрации ещё не выполнен. Текущий разбор «Архангельского леса» был делегирован до изменения навыка по прямому поручению пользователя и не считается такой проверкой.
